# Portfólio ERP — Oracle APEX

Projeto de portfólio desenvolvido com **Oracle APEX, SQL e PL/SQL**, com o objetivo de demonstrar conhecimentos práticos em desenvolvimento de aplicações corporativas, modelagem de dados e implementação de regras de negócio.

O projeto simula um sistema ERP com módulos integrados para gestão de informações e processos empresariais, servindo como demonstração prática das minhas habilidades como desenvolvedor Oracle APEX.

## Tecnologias utilizadas

- **Oracle APEX** — desenvolvimento da aplicação web.
- **Oracle Database** — armazenamento e gerenciamento dos dados.
- **SQL** — consultas, relacionamentos e manipulação de dados.
- **PL/SQL** — implementação de regras de negócio, procedures, functions e triggers.

## Funcionalidades e módulos

- **Núcleo do sistema:** estrutura central da aplicação e acesso aos módulos.
- **Gestão de usuários e acessos:** autenticação e controle de permissões.
- **Gestão organizacional:** empresas, contratos, colaboradores, setores e estrutura organizacional.
- **Gestão de processos:** configuração e acompanhamento de processos e etapas de fluxo de trabalho.
- **Relatórios e dashboards:** visualização de informações para apoio à análise e tomada de decisão.

O projeto está em desenvolvimento contínuo, com possibilidade de expansão de funcionalidades e módulos.
